# Копирка

Локальная библиотека визуальных референсов — аналог Eagle. Плотная сетка превью,
папки, теги, поиск. Захват через Chrome-расширение, drag&drop, ⌘V и автоимпорт
папки скриншотов.

Файлы физически лежат на диске владельца, сервер локальный, облака нет.

Продуктовая документация — в `../wiki/` и `../work/проектирование/`.
Приёмка Фазы 0 идёт **по функциональной карте**, по списку из 34 MVP-функций.

## Требования

- macOS
- Node 22+ (нативные модули `sharp` и `better-sqlite3` собираются под него)
- Chrome — для расширения

## Запуск для разработки

```bash
cd app
npm install
npm run dev
```

Поднимается два процесса: сервер на `http://127.0.0.1:43117` и дев-сервер интерфейса
на `http://localhost:5173` (проксирует `/api` на сервер). Открывать надо **5173** —
там горячая перезагрузка.

## Запуск как приложения

```bash
cd app
npm run build      # собирает интерфейс, затем сервер
npm start          # сервер поднимается и сам открывает браузер
```

Интерфейс — `http://127.0.0.1:43117`, статику раздаёт тот же сервер.

## Где что лежит

| Путь | Что это |
|---|---|
| `shared/api.ts` | Контракт HTTP-API. Первоисточник имён и типов для обеих сторон |
| `server/` | Локальный сервер: SQLite, импорт, дедупликация, превью, отдача файлов |
| `web/` | Интерфейс: React 19 + Vite + Tailwind v4 |
| `web/DESIGN-SPEC.md` | Визуальная спека, снятая с макетов |
| `web/src/styles/tokens.css` | Токены дизайн-системы. Первоисточник визуальных значений |
| `extension/` | Chrome-расширение MV3 — см. `extension/README.md` |
| `folder-action/` | Автоимпорт папки скриншотов — см. `folder-action/README.md` |

## Данные на диске

```
~/Pictures/Копирка/
├── library.db        # SQLite, единственный файл БД
├── originals/        # ab/cd/<sha256>.jpg — шардирование по первым 4 hex-символам
└── previews/         # та же схема, WebP
```

Имя файла — это `sha256` оригинала: исключает коллизии имён и даёт бесплатную
проверку точного дубля.

Конфиг приложения лежит **вне** библиотеки — `~/Library/Application Support/Kopirka/config.json`
(путь библиотеки, порт, флаг первого запуска). Иначе получилась бы циклическая
зависимость: путь нужен раньше, чем открывается база.

Встроенного бэкапа нет и не планируется: библиотека — обычная папка, её покрывает
Time Machine.

## Проверка

```bash
npm run typecheck --workspace=server
npm run typecheck --workspace=web
npm run smoke --workspace=server     # 22 сквозные проверки на временной библиотеке
node extension/tools/verify.mjs      # целостность манифеста расширения
```

`smoke` поднимает сервер на свободном порту во временной папке и проверяет весь
конвейер: импорт, оба уровня дедупликации, корзину с восстановлением, правило
«Не разобрано», нормализацию тегов, удаление папки, лимиты, битые файлы,
занятый порт, автоочистку. Настоящую библиотеку не трогает.

## Переменные окружения

Нужны в основном для тестов — в обычной работе не задаются.

| Переменная | Что делает |
|---|---|
| `KOPIRKA_LIBRARY_PATH` | Путь библиотеки в обход конфига |
| `KOPIRKA_CONFIG_DIR` | Другая папка конфига |
| `KOPIRKA_PORT` | Другой порт |
| `KOPIRKA_NO_OPEN` | Не открывать браузер при старте |
| `KOPIRKA_QUIET` | Тише в консоли |
