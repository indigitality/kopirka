# Как установить «Копирку» на Windows

«Копирка» — локальная библиотека визуальных референсов: плотная сетка превью,
папки, теги, поиск. Все файлы хранятся у вас на диске, без облака.

Это инструкция для Windows. Версия для Mac ставится иначе — про неё
[`install-guide.md`](./install-guide.md).

## Что понадобится

- **Windows 10 (64-битная) или Windows 11.** Для Windows 10 нужна версия 1809
  или новее — почти любая система, которая получала обновления в последние годы,
  подходит. Проверить: **Win+R** → напечатать `winver` → Enter; в окне будет
  строка «Версия 22H2» или похожая.
- **Процессор Intel или AMD (x64).** Сборки для ARM-ноутбуков (Windows on ARM,
  Snapdragon) нет.
- **Chrome** — если хотите сохранять картинки прямо из браузера через расширение
  «Копирку». Без него приложение тоже работает: перетаскиванием и вставкой из
  буфера обмена.

Больше ничего ставить отдельно не нужно: и сервер библиотеки, и всё, чем
рисуется интерфейс, лежат внутри установщика.

## Что качать

Файл один:

| Файл | Что это |
|---|---|
| `Kopirka_0.2.0_x64-setup.exe` | Установщик «Копирки» для Windows, 64 бита |

Ссылку даёт Сергей — оттуда же, откуда качают версию для Mac.

Имя файла латиницей нарочно: русские буквы в именах файлов переживает не всякая
пересылка и не всякий распаковщик архивов. Внутри приложение остаётся «Копиркой»
— и в меню «Пуск», и в списке установленных программ.

## Установка

1. Запустите скачанный `Kopirka_0.2.0_x64-setup.exe` двойным кликом.
2. Windows покажет предупреждение о неизвестном издателе — как его пройти,
   в следующем разделе.
3. Дальше обычный установщик: несколько экранов с кнопкой «Далее» и «Установить».
   Прав администратора он не просит — «Копирка» ставится только для вас, в вашу
   же папку, поэтому окна UAC («Разрешить приложению вносить изменения?»)
   не будет.
4. По окончании в меню «Пуск» появится «Копирка». Открывать её оттуда: нажмите
   **Пуск** и начните печатать «Копирка».

Установщик может занять минуту-две: внутри целый локальный сервер. Про
компонент **WebView2**: интерфейс «Копирки» рисуется тем же движком, что
Microsoft Edge. В Windows 11 он есть изначально, в Windows 10 может не быть —
тогда установщик доставит его сам и молча, для этого нужен интернет.

### Если Windows заблокировала запуск (SmartScreen)

«Копирка» распространяется без подписи разработчика — сертификат стоит денег,
а приложение раздаётся бесплатно. Поэтому Windows видит незнакомую программу
и на всякий случай её останавливает. Это та же история, что с блокировкой
неподписанных приложений на Mac: предупреждение говорит не «программа плохая»,
а «я про неё ничего не знаю».

Как пройти:

1. Появится синее окно **«Система Windows защитила ваш компьютер»**
   (SmartScreen) с одной кнопкой «Не выполнять».
2. Нажмите ссылку **«Подробнее»** — она неприметная, под текстом.
3. Раскроется строка с именем файла и издателем, а под ней кнопка
   **«Выполнить в любом случае»**. Нажмите её.

После этого установщик пойдёт как обычно. Повторно это окно не появится:
предупреждение относится к запуску скачанного файла, а не к самой «Копирке» —
установленное приложение открывается обычным кликом.

Формулировки в этом окне Microsoft время от времени меняет, и кнопки у вас
могут называться чуть иначе. Смысл один: раскрыть «Подробнее» и разрешить запуск.

Ещё две вещи, которые могут случиться по дороге, и обе не поломка:

- **Браузер при скачивании** может сказать, что файл скачивают редко и он может
  быть опасен. В Chrome нужно в списке загрузок нажать на файл правой кнопкой →
  «Сохранить» (или «Сохранить всё равно» в появившейся полоске).
- **Антивирус** может подержать файл на проверке или попросить подтверждения.
  Если он удалил установщик молча — напишите Сергею, разберёмся.

## Первый запуск

Откройте «Копирку» из меню «Пуск». Откроется один экран — «Соберём библиотеку
референсов». Мастера из нескольких шагов нет, всё на одном экране:

1. Поле **«Путь библиотеки»** уже заполнено значением по умолчанию — это папка
   `Изображения` вашего профиля, то есть `C:\Users\<ваше имя>\Pictures\Копирка`.
   Можно оставить как есть или нажать **«Выбрать папку…»** и указать другое
   место на диске.
2. Нажмите **«Создать библиотеку»**. Если папки ещё нет — «Копирка» создаст её
   сама. Путь всегда можно поменять позже в настройках.

Под полем — короткая подсказка, как наполнять библиотеку: перетаскиванием
картинок в окно, вставкой из буфера обмена (Ctrl+V) и через расширение Chrome.
Подробнее — в разделе «Как добавлять референсы» ниже.

В отличие от Mac, никаких системных запросов разрешений при первом запуске
Windows не показывает — ни на уведомления, ни на что-либо ещё.

### Приложение живёт в трее

«Копирка» — не обычное окно, а приложение со значком в области уведомлений
(трее) — там, где часы в правом нижнем углу. Крестик на окне его **не
закрывает**: окно просто прячется, а приложение продолжает работать в фоне —
принимает файлы из расширения Chrome и показывает уведомления.

Что делает значок в трее:

- **левый клик** — открыть окно библиотеки;
- **правый клик** — меню: «Показать библиотеку», строка «Не разобрано: N»
  (открывает этот раздел) и **«Выйти»**.

Выйти из «Копирки» полностью можно только через пункт **«Выйти»** в этом меню.
Строки меню у приложения на Windows нет, и сочетания вроде Ctrl+Q для выхода
тоже нет — это не пропущенная деталь, а решение: меню жило бы внутри окна
поверх тёмного интерфейса.

Windows 11 по умолчанию прячет часть значков трея под стрелку рядом с часами:
если значка «Копирки» не видно — нажмите эту стрелку. Чтобы он всегда был
на виду, вытащите его оттуда на панель мышью или включите в **Параметрах →
Персонализация → Панель задач → Другие значки в области уведомлений**.

## Уведомления

«Копирка» показывает уведомления обо всём, что приезжает в библиотеку мимо
открытого окна: расширение Chrome сохранило картинку, сняло скриншот вкладки
или области. Про перетаскивание и Ctrl+V уведомления не приходят, пока вы
смотрите в окно — там и так видно, что карточка появилась; если окно спрятано,
уведомление придёт.

Выглядит это как обычное уведомление Windows в правом нижнем углу: заголовок
«Копирка», текст вида «Добавлено 3 файла».

Отдельного запроса разрешения на уведомления Windows не показывает — ничего
подтверждать не нужно.

Одна важная деталь: **уведомления работают только у «Копирки», поставленной
установщиком.** Windows привязывает право показывать тосты не к самой
программе, а к ярлыку в меню «Пуск», который кладёт установщик. Поэтому
приложение, запущенное из распакованной куда-нибудь папки, молчит — но файлы
всё равно попадают в библиотеку.

Если уведомлений нет: проверьте **Параметры → Система → Уведомления** — там
должен быть включён общий переключатель и «Копирка» в списке приложений ниже.
И убедитесь, что не включён режим **«Не беспокоить»** (в Windows 10 —
«Помощник сосредоточенности»): в нём Windows придерживает тосты у всех
программ.

## Как добавлять референсы

На Windows три способа.

- **Перетаскивание.** Перетащите картинки из Проводника или прямо из браузера
  в окно «Копирки».
- **Ctrl+V.** Скопируйте картинку где угодно и вставьте в окне «Копирки».
- **Расширение Chrome** — из браузера, см. ниже. Оно же умеет снимать скриншот
  вкладки и выделенной области страницы.

Про системные скриншоты. Снимок, сделанный **Win+Shift+S** («Ножницы»), Windows
кладёт в буфер обмена — дальше должен работать обычный Ctrl+V в окне «Копирки».
Именно этот путь на живой Windows пока не проверяли: если вставка не сработает,
сохраните снимок файлом и перетащите его в окно.

Чего в Windows-версии **нет** — честно, чтобы не искать:

- **захвата области экрана по горячей клавише** (на Mac это ⌥⌘C — снимок любого
  места системы прямо в библиотеку);
- **автоимпорта папки** — чтобы всё попавшее в выбранную папку само уезжало
  в библиотеку;
- **пункта «Добавить в Копирку» в контекстном меню Проводника** — правым кликом
  по файлу в папке добавить нельзя, нужно перетащить.

Это не «пока не сделали к релизу», а состав Windows-версии на сегодня.

### Расширение Chrome

Расширение одно и то же для Windows и Mac. В Chrome Web Store оно пока не
опубликовано, поэтому ставится вручную, распакованным:

1. Получите архив с расширением (пришлёт Сергей, вместе со ссылкой на
   установщик).
2. Распакуйте архив: правый клик по нему в Проводнике → **«Извлечь все…»** →
   «Извлечь». Chrome умеет ставить расширение только из папки, из архива —
   не умеет.
3. Откройте в Chrome страницу `chrome://extensions`.
4. Включите переключатель **«Режим разработчика»** в правом верхнем углу.
5. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную
   папку.

Chrome будет при каждом запуске браузера показывать напоминание про расширения
в режиме разработчика — это нормально, просто закройте его.

Что умеет расширение:

- правый клик по картинке на любой странице → **«Сохранить в Копирку»**;
- значок расширения на панели → скриншот видимой области вкладки или снимок
  выделенной области страницы.

Для работы расширения приложение «Копирка» должно быть запущено — иначе
расширение честно скажет, что «Копирка не запущена».

Расширение обращается к приложению по адресу `http://127.0.0.1:43117` — это
порт «Копирки» по умолчанию. Менять адрес в расширении нужно, только если порт
был изменён в самом приложении (Настройки → «Дополнительно» → «Порт») — тогда
тот же адрес указывается на странице настроек расширения (значок расширения →
шестерёнка → поле «Адрес сервера»).

## Горячие клавиши

Те же, что на Mac, только вместо ⌘ — Ctrl:

| Клавиши | Что делают |
|---|---|
| `Ctrl+K` | Встать в поиск |
| `Ctrl+A` | Выделить всё в сетке |
| `Ctrl+C` | Скопировать выделенное в буфер обмена |
| `Ctrl+V` | Вставить картинку из буфера в библиотеку |
| `Ctrl+1` `Ctrl+2` `Ctrl+3` | Большие, средние, маленькие карточки |
| `Delete` | Отправить выделенное в корзину |
| `Esc` | Снять выделение, закрыть просмотр карточки |
| `←` `→` | Листать карточки в открытом просмотре |

Корзина здесь своя, «Копиркина», а не системная: удалённое лежит в разделе
«Корзина» слева и окончательно исчезает через 30 дней.

## Где хранятся файлы

**Библиотека** — обычная папка на диске, по умолчанию
`C:\Users\<ваше имя>\Pictures\Копирка`. В ней:

- `library.db` — единственный файл базы данных;
- `originals\` — сами файлы, названы по `sha256`;
- `previews\` — превью для сетки, в том же виде.

**Настройки и журналы** лежат отдельно от библиотеки, в `%APPDATA%\Kopirka`:

- `config.json` — путь к библиотеке и порт;
- `kopirka.log` — журнал сервера библиотеки;
- `kopirka-shell.log` — журнал самой оболочки приложения.

**Само приложение** — в `%LOCALAPPDATA%\Копирка`.

Быстрый способ открыть любую из этих папок: **Win+R**, вставить путь
(например `%APPDATA%\Kopirka`), Enter. Или вставить тот же путь в адресную
строку Проводника.

Отдельного бэкапа внутри «Копирки» нет и не планируется: это обычная папка
с файлами, её покрывает любое ваше резервное копирование.

## Как обновляться

Автообновления нет — новую версию нужно ставить руками:

1. Скачайте новый установщик.
2. Выйдите из «Копирки» полностью: правый клик по значку в трее → **«Выйти»**
   (крестика на окне недостаточно, см. выше).
3. Запустите новый установщик и поставьте поверх — старую версию удалять
   не нужно.

Библиотека и настройки при этом не трогаются: библиотека — это папка, выбранная
при первом запуске, а настройки хранятся в `%APPDATA%\Kopirka`, то есть вне
самого приложения.

Удаляется «Копирка» как обычная программа: **Параметры → Приложения →
Установленные приложения → Копирка → Удалить**. Библиотеку удаление
не затрагивает — её при желании нужно убрать руками.

## Если что-то не работает

Пишите в Telegram Сергею: **https://t.me/orshaks**. В самом приложении внизу
левой панели есть пункт **«Сообщить об ошибке»** — он ведёт туда же.

К сообщению приложите:

- скриншот того, что происходит;
- версию «Копирки» — **Настройки → раздел «О программе» → «Версия
  приложения»**;
- версию Windows — **Win+R** → `winver` → Enter, и скриншот этого окна.

Два случая, которые можно разобрать самому:

- **Окно «Порт занят — Копирка не запустилась».** Порт 43117 занят другой
  программой. В этом же окне есть кнопка **«Сбросить порт на 43117»** и кнопка
  выхода; если сброс не помог, значит порт держит кто-то посторонний — закройте
  эту программу и откройте «Копирку» заново.
- **Приложение не открывается вовсе.** Заглядывать нужно в
  `%APPDATA%\Kopirka` — в файлы `kopirka-shell.log` и `kopirka.log`. Последние
  строки оттуда сильно ускорят разбор, приложите их к сообщению.

## Известные ограничения этой версии

- **Windows-версия новая.** Она проверена автотестами, но живьём на разных
  машинах ходила мало: если что-то ведёт себя не так, как здесь написано, это
  скорее повод написать Сергею, чем ваша ошибка.
- Сборка только под x64 — для ARM-ноутбуков (Snapdragon) версии нет.
- Подписи разработчика нет, поэтому при первом запуске установщика Windows
  показывает предупреждение SmartScreen — как проходить, написано выше.
- Нет захвата области экрана по горячей клавише, автоимпорта папки и пункта
  в контекстном меню Проводника — способы добавления перечислены выше.
- Расширение есть только для Chrome и ставится распакованным.
- Автообновления нет — новую версию нужно ставить руками.
- Уведомления работают только у «Копирки», поставленной установщиком.
