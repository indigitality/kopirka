# Как установить «Копирку»

«Копирка» — локальная библиотека визуальных референсов: плотная сетка превью,
папки, теги, поиск. Все файлы хранятся у вас на диске, без облака.

## Что понадобится

- **Mac с macOS 13 или новее.** Подходят и Apple Silicon, и Intel — образы разные,
  какой ваш, см. следующий раздел.
- **Chrome** — если хотите сохранять картинки прямо из браузера через расширение
  «Копирка». Без него приложение тоже работает: перетаскиванием, вставкой из
  буфера и снимками экрана.

## Какой образ качать

Файлов два, отличаются только процессором, под который собраны:

| Файл | Для какого Mac |
|---|---|
| `Копирка_0.2.0_aarch64.dmg` | Apple Silicon — чипы M1, M2, M3, M4 и новее |
| `Копирка_0.2.0_x64.dmg` | Intel |

Свой процессор можно посмотреть за пару секунд: меню **Apple** (яблоко в левом
верхнем углу экрана) **→ «Об этом Mac»**.
Строка **«Чип: Apple M…»** — качайте `aarch64`. Строка **«Процессор: Intel…»** —
качайте `x64`. Всё остальное в установке и работе одинаково.

## Установка

1. Откройте `.dmg`-файл, который прислал Сергей.
2. Перетащите значок «Копирки» в папку «Программы».
3. Откройте «Копирку» из «Программ» (или через Launchpad) двойным кликом.

### Если macOS заблокировала приложение

«Копирка» распространяется без подписи Apple — сертификат разработчика стоит
денег, а раздаётся приложение бесплатно участникам клуба. При первом запуске
macOS его заблокирует. Путь один и тот же на macOS 15 Sequoia и macOS 26 Tahoe:

1. Дважды кликните по «Копирке» — macOS покажет, что открыть не может, и
   предложит закрыть диалог. Закройте его.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз. Там будет строка вида «„Копирка" заблокировано, чтобы
   защитить Mac» и кнопка **«Все равно открыть»**. Нажмите её.
4. В повторном диалоге нажмите **«Открыть»** — может потребоваться пароль
   учётной записи или Touch ID.

После этого «Копирка» будет открываться обычным двойным кликом, без вопросов.

Важно: старый способ через **правый клик → «Открыть»** на современных версиях
macOS для неподписанных приложений больше не работает — нужно именно через
Системные настройки, как описано выше. И ещё одна деталь: кнопка «Все равно
открыть» показывается около часа после попытки запуска, потом нужно будет
попробовать открыть приложение ещё раз, чтобы она появилась снова.

## Первый запуск

После разблокировки откроется один экран — «Соберём библиотеку референсов».
Мастера из нескольких шагов нет, всё на одном экране:

1. Поле **«Путь библиотеки»** уже заполнено значением по умолчанию —
   `~/Pictures/Копирка`. Можно оставить как есть или нажать **«Выбрать
   папку…»** и указать другое место на диске.
2. Нажмите **«Создать библиотеку»**. Если папки ещё нет — «Копирка» создаст
   её сама. Путь всегда можно поменять позже в настройках.

Под полем — короткая подсказка, как наполнять библиотеку: перетаскиванием
картинок в окно, вставкой из буфера обмена (⌘V) и через расширение Chrome.
Подробнее — в разделе «Как добавлять референсы» ниже.

### Приложение живёт в строке меню

«Копирка» — не обычное окно, а приложение со значком в строке меню (вверху
экрана). Крестик на окне его **не закрывает** — окно просто прячется, а
приложение продолжает работать в фоне: ловит ⌥⌘C, принимает файлы из
расширения и из автоимпорта.

Чтобы выйти полностью — ⌘Q или пункт **«Выйти»** в меню значка в строке меню
(то же самое можно сделать через меню «Копирка» → «Выйти из Копирки» в верхней
панели, когда окно приложения активно).

## Разрешения macOS

Система дважды спросит разрешения — оба раза можно сказать «да» сразу, а
можно и позже через настройки.

### Запись экрана — для ⌥⌘C

Снимок выделенной области (⌥⌘C) технически устроен как системная команда
`screencapture`, а ей нужно разрешение на запись экрана. При первом нажатии
⌥⌘C macOS сама покажет запрос — разрешите его.

Если случайно отказали или запрос не появился, включите разрешение руками:
**Системные настройки → Конфиденциальность и безопасность → Запись экрана** →
включите переключатель у «Копирки». После этого приложение нужно перезапустить
— это требование самой macOS, а не «Копирки». Пока разрешения нет, вместо
снимка придёт уведомление с этой же подсказкой — молча ничего не потеряется.

### Уведомления

«Копирка» показывает системные уведомления обо всём, что происходит мимо
открытого окна: сработал автоимпорт папки, расширение Chrome сохранило
картинку, сработала быстрая команда Finder или ⌥⌘C.

При первом запуске macOS спросит разрешение на уведомления — ответьте на запрос
сразу, не закрывая «Копирку»: система задаёт этот вопрос один раз, и если
приложение закрыть, не ответив, она засчитает отказ. Если уведомления не
приходят — **Системные настройки → Уведомления → Копирка** → разрешить.
Файлы при этом всё равно попадут в библиотеку, просто без подтверждения на
экране.

## Как добавлять референсы

- **Перетаскивание.** Перетащите картинки из Finder или браузера прямо в окно
  «Копирки».
- **⌘V.** Скопируйте картинку куда угодно и вставьте в окне «Копирки».
- **⌥⌘C — снимок области из любого приложения.** Работает не только внутри
  «Копирки», а в любом месте системы: нажмите ⌥⌘C, выделите область родной
  рамкой macOS — снимок сам уйдёт в библиотеку. `Esc` до отпускания мыши —
  отмена, ничего никуда не уходит.
- **Правый клик по картинке (или нескольким) в Finder → «Добавить в
  Копирку».** Пункт стоит на верхнем уровне контекстного меню, обычно внизу —
  не путайте с подменю «Быстрые действия». Появляется сам, после первого
  запуска приложения — устанавливать вручную ничего не нужно. Если пункта нет
  ни там, ни в «Быстрых действиях»: **Системные настройки → Основные →
  Объекты входа и расширения → Расширения → Finder** и включите там «Добавить
  в Копирку».
- **Расширение Chrome** — из браузера, см. ниже.

### Расширение Chrome

Расширение пока не опубликовано в Chrome Web Store, поэтому ставится вручную,
распакованным:

1. Получите папку расширения (архивом, вместе со ссылкой на `.dmg` — пришлёт
   Сергей).
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите переключатель **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку
   расширения из архива.

Chrome будет при каждом запуске браузера показывать напоминание про
расширения в режиме разработчика — это нормально, просто закройте его.

Что умеет расширение:

- правый клик по картинке на любой странице → **«Сохранить в Копирку»**;
- значок расширения на панели → скриншот видимой области вкладки или снимок
  выделенной области.

Для работы расширения приложение «Копирка» должно быть запущено — иначе
расширение честно скажет, что «Копирка не запущена».

Расширение обращается к приложению по адресу `http://127.0.0.1:43117` —
это порт «Копирки» по умолчанию. Менять адрес в расширении нужно, только
если порт был изменён в самом приложении (Настройки → «Дополнительно» →
«Порт») — тогда тот же адрес указывается на странице настроек расширения
(значок расширения → шестерёнка → поле «Адрес сервера»).

### Автоимпорт папки скриншотов (для продвинутых)

Можно настроить так, чтобы всё, что попадает в выбранную папку (например,
папку системных скриншотов), само уезжало в библиотеку «Копирки», а исходник
удалялся в Корзину. Это делается отдельным скриптом через Терминал и требует
разрешения на автоматизацию — по отдельной инструкции, которую при
необходимости даст Сергей. Для обычной работы с «Копиркой» это не нужно.

## Как обновляться

Автообновления нет — новую версию нужно ставить руками:

1. Скачайте новый `.dmg`.
2. Закройте «Копирку» полностью — ⌘Q (крестика на окне недостаточно, см.
   выше).
3. Откройте новый `.dmg` и перетащите «Копирку» в «Программы» — macOS сама
   спросит про замену существующей версии, подтвердите.

Библиотека и настройки при этом не трогаются: библиотека — это папка,
выбранная при первом запуске, а настройки (путь к ней, порт) хранятся отдельно
от самого приложения.

## Где хранятся файлы

Библиотека — обычная папка на диске (по умолчанию `~/Pictures/Копирка`), в
ней:

- `library.db` — единственный файл базы данных;
- `originals/` — сами файлы, названы по `sha256`;
- `previews/` — превью для сетки, в том же виде.

Отдельного бэкапа внутри «Копирки» нет и не планируется — это обычная папка,
и её покрывает Time Machine, если она у вас включена.

## Если что-то не работает

Пишите в Telegram Сергею: **https://t.me/orshaks**. В самом приложении внизу
левой панели есть пункт **«Сообщить об ошибке»** — он ведёт туда же.

К сообщению приложите:

- скриншот того, что происходит;
- версию «Копирки» — посмотреть можно в самом приложении:
  **Настройки → раздел «О программе» → «Версия приложения»**.

## Известные ограничения этой версии

- Образы для Apple Silicon и для Intel раздельные — универсального нет.
- Расширение есть только для Chrome.
- Автообновления нет — новую версию нужно ставить руками (см. выше).
- При первом запуске macOS блокирует приложение как неподписанное — это
  ожидаемо, инструкция по разблокировке выше.
