# Расширение «Копирка» для Chrome

Захват референсов из браузера в локальную библиотеку «Копирка». Расширение ничего
не хранит само: оно отправляет находки локальному серверу приложения
(`http://127.0.0.1:43117` по умолчанию) по контракту `app/shared/api.ts`.

Что умеет:

| Функция | Как вызвать | Куда уходит |
|---|---|---|
| CAP-01 · сохранить картинку со страницы | правый клик по изображению → «Сохранить в Копирку» | `POST /api/import/url`, `sourceType: context_menu` |
| CAP-02 · скриншот видимой области | иконка расширения → «Снять скриншот видимой области» | `POST /api/import/capture`, `sourceType: tab_screenshot` |
| CAP-08 · скриншот выбранной области | иконка расширения → «Снять область» | `POST /api/import/capture`, `sourceType: area_screenshot` |

Manifest V3, без сборщика и без зависимостей: обычные ES-модули, HTML и CSS.

---

## Установка распакованным

1. Запустить приложение «Копирка» (без него расширение покажет «Копирка не запущена»).
2. Открыть `chrome://extensions`.
3. Включить «Режим разработчика» (переключатель справа сверху).
4. «Загрузить распакованное расширение» → выбрать папку `app/extension`.
5. Закрепить «Копирку» на панели: иконка-пазл → булавка у строки «Копирка».

После правки кода: на карточке расширения в `chrome://extensions` нажать «Обновить»
(круговая стрелка). Content script подхватывается при следующем вызове «Снять область»,
но открытые вкладки лучше перезагрузить.

## Проверка, что связка работает

1. **Сервер виден.** Иконка расширения → шестерёнка → «Проверить».
   Ожидаемо: «Копирка отвечает». Если «не отвечает» — приложение не запущено
   или в нём другой порт.
2. **Контекстное меню (CAP-01).** Правый клик по любой картинке на обычном сайте →
   «Сохранить в Копирку». Ожидаемо: системное уведомление «Добавлено в библиотеку».
   Повторное сохранение той же картинки → «Уже есть в библиотеке».
3. **Видимая область (CAP-02).** Иконка → «Снять скриншот видимой области» →
   предпросмотр → «Сохранить». Ожидаемо: галочка и закрытие popup через ~1,2 с.
4. **Выбранная область (CAP-08).** Иконка → «Снять область». Popup закрывается,
   страница затемняется, курсор — перекрестие, у курсора живые размеры.
   Протащить прямоугольник → popup открывается с предпросмотром именно этого куска.
   `Esc` до отпускания мыши — отмена без следов.
5. **На ретине.** Тот же пункт 4 на экране с `devicePixelRatio = 2`: вырезанный кадр
   должен совпадать с выделенным прямоугольником, а не быть смещённым или вдвое меньше.
6. **Сервер выключен.** Закрыть приложение, открыть popup. Ожидаемо: сразу «Копирка
   не запущена» и кнопка «Повторить», без ожидания первого действия.

## Устройство

```
manifest.json            MV3: разрешения, service worker, popup, страница настроек
tokens.css               копия дизайн-токенов из app/web/src/styles/tokens.css
base.css                 общие примитивы страниц: кнопки, поля, типографика
background/
  service-worker.js      контекстное меню, захват кадров, уведомления, роутер сообщений
content/
  area-select.js         оверлей выделения области (инжектится по требованию)
popup/                   popup.html · popup.css · popup.js — машина состояний захвата
options/                 страница настроек: адрес сервера, проверка связи
lib/
  api.js                 HTTP-клиент по контракту app/shared/api.ts, таймауты
  config.js              адрес сервера в chrome.storage.sync
  messages.js            тексты интерфейса и разбор ImportResponse
  pending.js             снятый, но не сохранённый кадр (chrome.storage.session)
  capture.js             вырезание кадра в OffscreenCanvas с учётом dpr
  tabs.js                проверка доступности вкладки, имя файла для кадра
  protocol.js            имена сообщений popup ↔ service worker ↔ content script
tools/
  verify.mjs             проверка целостности: манифест, ссылки, импорты, синтаксис
  make-icons.mjs         генерация иконок (мятный квадрат логотипа)
icons/                   icon16 · icon32 · icon48 · icon128
```

Состояния popup заданы таблицей переходов в `popup/popup.js` (`TRANSITIONS`) —
ровно те, что описаны в документе 06 §3.1: исходное · выбор области · предпросмотр ·
отправка · успех · сервер недоступен · ошибка сохранения. Плюс техническое `checking` —
проверка `GET /api/health` при открытии.

### Разрешения

| Разрешение | Зачем |
|---|---|
| `activeTab` | снять видимую область и включить выделение на вкладке, которую пользователь сам открыл |
| `scripting` | инжект оверлея выделения (CAP-08) |
| `contextMenus` | пункт «Сохранить в Копирку» (CAP-01) |
| `storage` | адрес сервера (`sync`) и снятый кадр между закрытием и открытием popup (`session`) |
| `notifications` | три уведомления контекстного меню |

`host_permissions` — только `http://127.0.0.1/*` и `http://localhost/*`.
Порт в шаблонах Chrome указать нельзя (шаблон описывает хост, но не порт), поэтому
разрешён петлевой адрес целиком: любой порт на своей машине и ничего снаружи.
`<all_urls>` не запрашивается — доступ к странице даёт `activeTab` в момент клика.

## Известные ограничения

- **Служебные страницы.** На `chrome://…`, `chrome-extension://…`, `devtools://…`,
  `view-source:` и в Chrome Web Store Chrome запрещает и инжект, и захват. Расширение
  проверяет адрес заранее и пишет «На служебных страницах Chrome расширения не работают»,
  а не падает молча.
- **Локальные файлы (`file://`).** Работают, только если на карточке расширения включена
  галочка «Разрешить доступ к файлам».
- **Приложение должно быть запущено.** Без него любое действие заканчивается
  «Копирка не запущена». Расширение не поднимает сервер и ничего не копит на потом.
- **Картинки с адресом `blob:`** (некоторые редакторы и просмотрщики) сервер скачать
  не может — расширение предлагает снять их областью.
- **Возврат в popup после выделения области.** Chrome 127+ открывает popup сам
  (`chrome.action.openPopup`). В более старых версиях и когда окно браузера не в фокусе
  на иконке появляется значок, а уведомление просит открыть popup вручную — кадр к тому
  моменту уже снят и ждёт в `chrome.storage.session`.
- **Кадр живёт 10 минут** и не переживает перезапуск браузера: `storage.session` на диск
  не пишется.
- **Шрифты.** Geist берётся, только если установлен в системе; из сети расширение
  ничего не грузит, фолбэк — системный шрифт.
- **Одно окно за раз.** Выделение области работает в верхнем фрейме вкладки; оверлей
  переживает прокрутку и `transform` на `body` (хост висит на `documentElement`), но
  `transform` на самом `<html>` сдвинет его — таких страниц в природе почти нет.

## Проверки без Chrome

```bash
cd app/extension
node tools/verify.mjs      # манифест, ссылки в HTML, импорты, node --check по всем .js
node tools/make-icons.mjs  # перегенерировать иконки после смены токенов акцента
```

`verify.mjs` заодно следит, что в `permissions` не завелось лишнего и что в
`host_permissions` не появился порт (с портом Chrome не загрузит манифест).
