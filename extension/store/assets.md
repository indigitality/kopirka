# Материалы для публикации — что собрать руками

Проверено против официальной документации Chrome for Developers
(`developer.chrome.com/docs/webstore/images`, сентябрь 2026) — часть
цифр из исходного задания скорректирована, см. пометки «уточнение»
ниже.

## 1. Иконка магазина 128×128 — уже есть, но не идеально

`icons/icon128.png` есть, формат и размер верные (128×128 PNG,
проверено — `sips`: 128×128, альфа-канал есть). Отсмотрел все четыре
иконки (16/32/48/128) — лаймовый знак на тёмном скруглённом квадрате,
на 16 px всё ещё читается, артефактов и белых кромок по краю нет.
**Годится для публикации как есть.**

**Уточнение (необязательное, не блокер).** Официальная рекомендация
Google для иконки магазина: «видимая иконка — 96×96, вокруг неё 16 px
прозрачного поля с каждой стороны» — то есть 128×128 файла с полями.
`tools/make-icons.mjs` сейчас кладёт `INSET_RATIO = 0.0625` (8 px поля,
видимая часть 112×112) — фигура крупнее и поля вдвое уже, чем в
рекомендации Google. Это не ошибка и не причина отказа в ревью
(автоматической проверки на это нет), просто наша иконка будет
казаться немного крупнее соседних в сетке магазина. Если Сергей захочет
свести один в один — правка на одну константу
(`INSET_RATIO: 0.0625 → 0.125`) в `tools/make-icons.mjs` и перезапуск
`node tools/make-icons.mjs`; я эту правку не делал — иконки вне зоны
задачи, и решение о крупности знака дизайнерское, не техническое.

## 2. Скриншоты — нужны настоящие, черновики не подходят

**Требование Google:** 1280×800 **или** 640×400, от 1 до 5 штук,
**прямые углы, без полей (full bleed)** — картинка должна заполнять
кадр целиком, не «марка посередине белого листа». Все скриншоты одного
расширения должны быть одного из двух размеров (не смешивать).

Скриншоты, которые я снял для приёмки (раздел «Скриншоты» отчёта, путь
в scratchpad) — это popup в его настоящем размере 320×480, снятый для
проверки вёрстки, **не готовые кадры для магазина**: слишком маленькие,
с обрезанными полями. Годятся как референс «что показать», не как файл
для загрузки.

Что предлагаю показать (1280×800, до 5 кадров) — по одному кадру на
сценарий, popup крупным планом на фоне страницы или в рамке браузера,
без пустых полей:

1. **Правый клик по картинке на странице** — открытое контекстное меню
   с пунктом «Сохранить в Копирку» поверх настоящего сайта (референсы,
   Pinterest-подобная страница или дриббл).
2. **Popup, исходное состояние** — две кнопки («Снять скриншот видимой
   области» / «Снять область») и подсказка про правый клик.
3. **Popup, предпросмотр** — снятый кадр, кнопки «Сохранить» /
   «Переснять».
4. **Popup, успех** — лаймовая галочка и подпись «Добавлено в
   библиотеку».
5. **Выделение произвольной области на странице** — затемнённая
   страница, рамка выделения, живые размеры у курсора (оверлей
   `content/area-select.js`).

Кадры 2–4 у меня уже есть в увеличенном виде как заготовка (см. отчёт),
их нужно только красиво скомпоновать в 1280×800 (например, popup на
скриншоте реальной страницы браузера, а не на пустом фоне) — это
дизайнерская задача, не техническая, поэтому оставляю её Сергею или
следующей итерации.

## 3. Промо-плитки — уточнение: маленькая ОБЯЗАТЕЛЬНА, не опциональна

В задании обе плитки названы опциональными. По официальной
документации Google это верно только для большой:

| Плитка | Размер | Обязательна? |
|---|---|---|
| Маленькая (small promo tile) | 440×280 | **Да** — Google прямо помечает её «required»; без неё карточка хуже ранжируется в категориях и поиске |
| Марки (marquee) | 1400×560 | Нет — нужна, только если Google решит показать расширение на витрине/фиче |

Соответственно маленькую плитку 440×280 стоит подготовить до подачи, а
не после. Марки — можно пропустить на первую публикацию.

Содержимое обеих — тот же язык, что у иконки и логотипа: тёмная
панель `#1C1D1F`, лаймовый знак `#C5FD63`, можно добавить словесный
знак «Копирка» (тот же `web/src/assets/logo-wordmark.svg`). Вёрстка
плиток — не моя зона (растровый дизайн, не код расширения).

## 4. Что дальше

1. Собрать 1280×800 (или 640×400) скриншоты по списку в п.2.
2. Собрать маленькую промо-плитку 440×280.
3. (Опционально) марки 1400×560, если Сергей планирует подавать заявку
   на featuring.
4. (Опционально) перегенерировать иконки с полем 16 px вместо 8, если
   хочется совпасть с рекомендацией Google один в один.
5. Всё остальное для карточки — в `listing.md`, `permissions.md`,
   `privacy-policy.md`.

Источники цифр: `developer.chrome.com/docs/webstore/images` (размеры
иконки, скриншотов, промо-плиток; сентябрь 2026).
