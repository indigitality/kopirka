# Автоимпорт папки скриншотов (CAP-05)

Вешается на любую папку macOS. Всё, что туда попадает, уезжает в библиотеку
«Копирки», а исходник — в системную Корзину. Папка автоимпорта — **транзитная
зона, не хранилище** (PRD §5.8).

## Установка

```bash
cd app/folder-action
./install.sh ~/Desktop/Скриншоты
```

Скрипт положит обработчик в `~/Library/Application Support/Kopirka/`, скомпилирует
Folder Action в `~/Library/Scripts/Folder Action Scripts/` и привяжет его к папке.

На шаге привязки macOS один раз спросит разрешение на управление **System Events**.
Откажетесь — привязать можно руками: правый клик по папке → «Службы» →
«Настройка операций папки».

Чтобы снимки сразу падали в нужную папку:

```bash
defaults write com.apple.screencapture location ~/Desktop/Скриншоты && killall SystemUIServer
```

## Как устроено

`kopirka-folder-action.applescript` — только точка входа: macOS умеет вешать на
папку именно AppleScript. Вся логика в `kopirka-import.sh`.

Обработчик разбирает **всю папку целиком**, а не только что появившиеся файлы.
Это сделано намеренно: если приложение было выключено, накопившееся уедет при
следующем срабатывании. Очереди и повторов по таймеру нет — так в PRD §5.8.

| Ситуация | Поведение |
|---|---|
| Сервер не отвечает | Выход молча, файлы остаются в папке, причина — в лог |
| Файл принят (`added` / `added_similar`) | Исходник → Корзина, уведомление со счётчиком |
| Точный дубль (`duplicate`) | Исходник → Корзина, счётчик «дубли» |
| Сервер отклонил (формат, размер) | Файл остаётся в папке, строка в логе |
| Файл ещё дописывается | Пропускается, заберётся при следующем срабатывании |

Защита от двойного запуска — каталог-замок `/tmp/kopirka-folder-action.lock`,
брошенный замок старше 5 минут снимается автоматически. Folder Action легко
срабатывает несколько раз подряд, а мы обрабатываем всю папку — без замка
полетели бы дубли.

Перемещение в Корзину сделано через `mv` в `~/.Trash`, а не через Finder:
не требует разрешения на автоматизацию Finder.

Лог: `~/Library/Application Support/Kopirka/folder-action.log`.

## Решение, которого нет в PRD

**Точный дубль → тоже в Корзину.** PRD описывает судьбу исходника только для
успешной отправки. Если оставлять дубли в папке, они будут переотправляться при
каждом срабатывании и копиться вечно, а папка перестанет быть транзитной.
Помечено как `inference`, ждёт подтверждения Сергея — если решение не устроит,
меняется одной веткой `case` в `kopirka-import.sh`.

## Удаление

```bash
osascript -e 'tell application "System Events" to delete (every folder action whose name contains "Копирка")'
rm -f ~/Library/Scripts/Folder\ Action\ Scripts/Копирка\ —\ автоимпорт.scpt
rm -f ~/Library/Application\ Support/Kopirka/kopirka-import.sh
```
